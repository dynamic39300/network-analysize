# Relay 官网设计与交互

2026-09-26。依据 PRD-001 与 SPEC-001 商业化契约。

设计理解：面向个人 Mac 用户的专业网络诊断工具，以冷白、炭黑和克制绿色呈现已确认的 Relay 银黑信号弧品牌。原生 CSS、Django 模板与同域 JavaScript；DESIGN_VARIANCE 6、MOTION_INTENSITY 3、VISUAL_DENSITY 3。

## 视觉与页面

- 首页用非对称文字与真实 Relay 图标，不制作假窗口或假产品截图。报告示例是实际可切换场景、展开判断边界及复制文本的组件，清楚标注不会检测或修改当前网络。
- 功能页区分免费检查与 Pro 历史、快照对比、脱敏导出；价格页分别展示 Free 与 Pro，两种期限来自服务器定价。
- 账户、订单、支持使用同一导航，避免交易页重复营销结构。下载页只有已验证制品才提供可点击下载链接。
- 模式默认跟随系统，可依次切换浅色、深色与跟随系统；仅外观偏好写入浏览器本地存储。正文和按钮均用语义化主题变量。
- 系统字体适配中文与 Mac。面板圆角 20px、控件 10px、语义标签 6px；层级为页头 10、移动菜单 11、通知 30，弹窗使用原生 dialog 顶层。
- 动效只用于按钮交互反馈，不自动轮播、滚动劫持或持续闪烁；减少动态效果设置关闭过渡。767px 以下明确单列布局，导航变为可用键盘展开的菜单。

## 关键交互

- 邮箱验证码登录：条款勾选、获取验证码、重新发送冷却、修改邮箱、校验、错误重试。协议版本变更要求重新同意。开发模式说明邮件默认保存在运行端；不存在返回 OTP 的网页接口。
- 账号页面明确 Free / Pro 与原始权益状态。试用按钮打开确认弹窗，确认后才调用 trial/start；注册和登录不开始计时。
- 报价请求先于下单；服务端金额、币种变化会锁定购买并要求重新确认。表单保留幂等键用于重试。支付来源为服务器，二维码在本机生成；页面返回不被当作付款证据。
- 模拟付款仅在 development 且 config.payments.simulated=true 时出现。无真实商户时，未登录访客也能看到“真实购买暂未开放”。
- 订单可继续查单、提交退款申请、查看退款状态与关联支持工单；提交退款不显示为完成退款。
- 桌面登录只确认 PKCE 请求，不在浏览器接收或跳转带凭证的 callback URL。成功后用户返回正在等待的客户端。
- dialog 支持 Escape、自动焦点与关闭后焦点恢复；表单字段有真实 label，反馈使用 status/alert；错误、空态、骨架加载均具备。

## 资产与复用边界

品牌图标来自 assets/logo/Relay-logo-final.png，复制至 backend/static/relay-logo.png，未修改设计。官网 CSS 与 Relay 内容重新实现；同属用户的 AppSwitcher app.js 仅作为账号/订单/支持交互的工程起点，已移除其功能、定价、系统要求及退款承诺。二维码依赖保留 MIT 许可与来源记录，见 backend/static/vendor/README.md。

当前隐私与服务条款为公开上线前审阅稿，不编造经营主体、客服邮箱、退款时限或已经完成的签名发布。正式上线前必须补全运营信息并审核条款。

## 验证边界

2026-09-26 前端检查通过：

- `node --check backend/static/app.js`、`node --check backend/static/theme.js`。
- 独立 Chromium 151 上以隔离接口样例执行 DOM smoke，共 78 个 API 请求：公开页面、未知路径、登录后页面均能渲染；验证码错误后重试、主动试用确认、报价与同意后下单、开发模拟支付、退款申请、工单及补充、PKCE 确认可完成。没有未捕获 JavaScript 错误，不发送真实邮件、工单或付款。
- 检查每页只有一个 h1、无重复 DOM id、按钮具有名称；390px 手机宽度下公开与账号页面无横向溢出。报告场景切换、复制降级弹窗、Escape 关闭、主题切换及手机菜单通过。
- 实际 `http://127.0.0.1:8016` 对首页、功能、价格、下载、登录、支持、条款与隐私执行只读加载，验证静态资源、CSP 及无脚本错误。浅色、深色、390px 首页与价格页截图已目视检查。
- 对浅色与深色正文、次要文字、绿色状态文字与按钮前景／背景组合计算对比度，全部达到 4.5:1。

隔离脚本位于本机 `/tmp/relay-web-smoke.cjs`，实际服务只读脚本为 `/tmp/relay-live-smoke.cjs`；它们是本次验收辅助，不是生产依赖。截图为 `/tmp/relay-live-light.png`、`/tmp/relay-live-dark.png`、`/tmp/relay-live-mobile.png`、`/tmp/relay-live-pricing-mobile.png`。

# Relay 品牌设计说明

## 软件命名

**Relay**（英文，无中文名）

### 命名寓意
- **网络术语**：Relay（中继/接力）是网络通信中的核心概念，指信号在节点间传递放大
- **功能映射**：软件每 30 秒检测一次网络状态，发现问题后自动修复，整个过程如同信号的接力传递
- **发音**：单音节，简洁顺口，无拗口的中文翻译
- **独特性**：区别于 NetPulse、NetMedic 等常见网络工具命名，品牌识别度高

### Bundle ID 建议
`com.wangxinlei.relay`（原 `com.wangxinlei.networkdoctor` 可在 2.0 升级时同步更新）

## Logo 设计

### 最终方案
- **图形**：四段从下到上递增的金属信号弧形 + 底部圆心圆点
- **底色**：纯黑（带极微弱中心径向渐变）
- **图形色**：银白金属（拉丝金属质感，微妙高光反射）
- **画幅**：1:1 圆角方形 App 图标
- **风格**：极致极简、单焦点元素、黑白高对比

### 设计理念
- **信号弧**：四段递增弧形直接表达网络信号强度与监测，是软件核心功能（持续检测网络状态）的视觉转译
- **底部圆点**：代表信号源/网络节点，也是四段弧的几何圆心
- **递增节奏**：从短到长的弧形排列，暗示信号从弱到强、问题从发现到修复的过程
- **金属质感**：银白拉丝金属传达专业、精确、高级的工具属性

### 设计基因来源
对标 **Linear**（项目管理工具）的图标设计基因：
- 纯黑底 + 银白金属质感图形
- 极致极简，单焦点几何元素
- 微妙的金属颗粒纹理与高光
- 黑白高对比，小尺寸（16×16）仍可清晰识别
- 不依赖文字，纯图形传达品牌

### 视觉规范
| 维度 | 规范 |
|---|---|
| 背景色 | 纯黑 #000000（可带极微弱径向渐变） |
| 图形色 | 银白金属（受光面接近 #FFFFFF，背光面约 #B0B0B0） |
| 图形结构 | 底部圆点 + 四段递增九十度圆弧 |
| 安全区 | 图形周围保留均匀充足留白，不小于图标宽度的 15% |
| 最小尺寸 | 16×16 px 下仍可识别信号弧轮廓 |
| 禁用 | 不得添加文字、不得改变弧形数量、不得使用彩色渐变 |

## 设计过程摘要

1. **首轮 8 版试稿**：覆盖脉冲接力、守护透镜、字母标、莫比乌斯环、线描拓扑、十字信号、对话气泡、指南针等方向，用户均不满意
2. **标杆调研**：分析 Raycast、Arc、Linear、CleanMyMac、iStat Menus、Things 3 六个优秀 macOS 工具图标，提炼出"单一焦点元素 + 直接功能隐喻 + 有记忆点配色 + 明确质感"的核心基因
3. **基因锁定**：用户选定 Linear 的"极致极简 + 金属质感 + 黑白对比"基因
4. **Linear 基因试稿**：生成 R 字母、信号弧、脉冲折线三版，用户选定信号弧方向
5. **最终优化**：基于信号弧方向精细化金属质感与弧形比例，产出最终主版本

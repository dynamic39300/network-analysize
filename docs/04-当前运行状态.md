## 4. 本地安装部署（当前基线，可复现）

```bash
# 安装目录
mkdir -p "$HOME/Library/Application Support/网络助手"
/usr/bin/python3 -m venv "$HOME/Library/Application Support/网络助手/.venv"
"$HOME/Library/Application Support/网络助手/.venv/bin/pip" install rumps setproctitle
cp code/network-doctor-menu.py "$HOME/Library/Application Support/网络助手/"

# launchd 自启（deploy/com.wangxinlei.networkdoctor.plist 已归档）
launchctl bootstrap "gui/$(id -u)" "$HOME/Library/LaunchAgents/com.wangxinlei.networkdoctor.plist"
```

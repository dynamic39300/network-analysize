# SPEC-008：默认 Agent 工作台与既有能力兼容

2026-09-27。落实 PRD-002 默认体验的一部分，不改变完整蓝图或收费规则，不等于安装升级和整体产品验收完成。

## 默认入口

源码 `code/network-doctor-menu.py` 和新构建 App 的无参数启动进入独立核心工作台；`--agent-desktop` 是同义显式入口。`--core-service` / `--lifecycle` 保留服务分流。`--self-check` 仍只检查导入/资源，不打开窗口、不读 Keychain、不探测网络，并报告 `desktopEntry=agent`。

`--legacy-desktop` 仅保留旧桌面回退，不接受混合 Agent 角色参数。原目录已有旧运行时或不可连接的核心持锁时不接管、不终止它；先正常收尾旧进程。新桌面另有私有 `desktop.lock`，拒绝同目录第二个桌面实例。该锁不是跨目录账号进程锁，也不是签名身份认证。

普通启动不迁移或覆盖已安装 App，不默认注册登录服务。用户明确停止过核心时，重开仍保持停止；恢复已保存的守护仅采用新核心的独立选择，不导入旧 `guard.enabled` / `auto_fix` 作为权限。其他生命周期合同沿用 SPEC-007。

## 账号与报告

`DesktopServices` 从原菜单控制器提取账号、签名权益、本地历史和文件导出逻辑，新旧桌面共用。它只接收快照读取函数与事件回调，不持有 Agent、CoreRuntime、修复授权或模型凭据。账号队列、历史队列和文件队列各自有上限，不在 Cocoa 线程等待 HTTP、Keychain、SQLite 或退出收尾。

设置保留浏览器登录、取消、退出、同步和账户页；静态界面状态来自缓存。PKCE、固定服务源、签名权益、离线缓存与 Keychain 继续使用已有 commercial 模块。冻结包只读内置商业公钥配置，不接受源码环境覆盖。缺少配置/依赖、账号离线或权益到期不限制核心任务、健康档案、修复授权流程及基础报告。

取消登录后收到迟到成功，会在同一账号工作线程清除该会话。退出桌面先停止收新操作，后台等账号和文件工作收尾，再退出应用，不阻塞主线程也不停止核心。主动强退不受合作退出协议保证。账号退出不撤销或创建核心范围授权、模型上传同意、守护选择；这些有独立入口。

Agent 的处理记录/时间线/收据继续免费。原 Pro 历史仍为同目录 `history.sqlite3`，不搬迁、不清空、不升级成核心权限库；继续采用 30 天范围、相同结果去重和已有权益核验。处理记录工具栏与菜单可读最近 20 次不同结果、比较最近两次、导出最多 200 条 HTML/JSON 诊断包；选择目录后再次校验权益。到期拒绝 Pro 操作但保留已有数据，不影响基础报告。

Pro 快照只在桌面运行、观察到核心已提交且带检测时间的结果、权益有效时记录。账号恢复较慢时可补记当前可见结果；不承诺补齐桌面关闭期间的每次检测，Agent 持久日志与商业快照不是同一存储。历史摘要展示当时观测而非当前健康，完整数据独立保留；普通报告排除账号凭据、原始网络标识及私有命令输出。

## 检测配置

预设和重新识别通过版本化 IPC 进入核心串行队列：`detection_preset` 仅允许四个已有预设，`detection_redetect` 不接受额外配置、权限或执行字段。核心检查当前修订、配置读取是否成功及磁盘内容摘要，拒绝待确认方案期间修改。

在临时副本上应用预设或有预算的只读识别，保存前再次检查取消和磁盘变化；失败保留原内存和文件。它是对合作配置修改的乐观冲突检测，不宣称能阻止任意外部编辑器在最终检查与写入之间竞态。外部文件已变动时拒绝覆盖，用户需正常停止并重启核心后重新读取。配置读取失败时只读，不覆盖损坏文件。

开始重新配置即使旧修复权限失效，临时暂停守护；成功保存后清空旧检测结果。若此前明确启用守护且期间没有停止/取消，恢复已有守护选择；不代用户启用。重新识别后进行有预算只读检测。已保存 HealthProfile 目标/预期不被现场识别改写，模型上传同意保持独立；这些操作不创建系统授权。

## 验证与差距

`test_desktop_services.py`、`test_detection_settings.py`、`test_desktop_compat_native.py` 检查共享逻辑、真实私有 IPC、实际 Cocoa 点击/渲染及目录兼容；既有菜单、商业签名和历史回归继续运行。系统网络用 FakeMac，账号用模拟对象或内存签名夹具，浏览器仅模拟打开；本轮不读取真实用户账号或发起生产交易。

本地冻结包验证默认入口自检/参数分流与临时空闲核心启动/重连/停机；真实双击安装、旧安装升级、真实 Keychain/官网往返、后台 Pro 历史产品策略、Windows 完整桌面、可信签名/特权服务、无障碍与发布仍未完成。完整范围及实测数字分别见 TKT-002 和 QA-002。

# SPEC-006：成熟修复的任务与持续范围信任

2026-09-27。对应 PRD-002 授权交互、BLUEPRINT-001 F5/F8。入口为 macOS 源码连接桌面和独立核心，不表示 Windows、签名提权或任意动态命令高信任已完成。

## 模式

| 模式 | 默认 / 期限 | 范围 |
| --- | --- | --- |
| 逐次确认 | 默认；具体方案五分钟内一次有效 | 原有成熟或动态方案，动态另需风险确认 |
| 本次任务信任 | 显式选择；确认后最多 15 分钟、3 批方案，不超过原调查总时限 | 同一个 AgentRun，匹配审阅范围；结束后失效 |
| 限定范围持续信任 | 显式选择；确认后最多 8 小时、12 批方案 | 当前核心内后续调查或已启用守护，可跨任务，不跨核心重启 |

首次确认计入额度。每批方案而非每个字段计数；准备/执行失败不退回预留，不自动续期。新授权替换旧范围并记录被替换 ID。切换模式清空勾选，重新审阅默认回到逐次确认。没有默认高权限或管理员密码框。

守护、修改授权、模型上传和系统权限独立。创建信任不启用守护或给予上传/管理员权限，但会处理本页明确确认的方案。只读 `check` 和仅准备方案的 `propose` 不利用信任执行。调查、模型续接和守护可使用现有信任；每批仍经过前置核对、恢复材料、回读、保护目标验证与必要回退。

## 范围与升级

`relay-repair-trust-v1` 从核心生成的具体方案派生，不接受客户端自定义范围。目前接受成熟 DNS、IPv6、不可达本机代理开关动作，绑定：

- 健康档案 ID/版本、网络服务、Wi-Fi 接口、观测 IP/网络名和已有默认接口字段。
- VPN 状态、归属、接口、路径和锚点路由证据。
- 修改字段、精确目标值，代理动作的主机/端口。
- 成熟问题类别；公司 DNS 缺失与混用归为同一已保存公司 DNS 策略。

后续方案可包含获准动作的子集，不能新增字段、目标值、服务、档案、端点或权限字段。后续原值可以不同，必须重新保存并核对，界面明确说明这与单份方案授权的区别。不能只凭 SSID 建立新信任；当前系统接口/地址证据不是网络的密码学身份，复杂身份和受管策略仍需完善。

动态命令不依赖模型自报低风险进入范围；未知动作、未确认 VPN、缺少有效接口地址或不完整检查不提供范围信任。超出范围停在方案等待参与，不偷偷缩小后执行一部分。成熟动作新绑定包含 Wi-Fi 接口；存在 VPN 上下文时，代理和 IPv6 也在每次写入前复核归属/路由，代理仍需核对原端点不可达。原值变化、第三方配置和执行器其他拒绝条件继续有效。

## 执行与撤销

`RepairTrust` 集中创建、匹配、预留、逐写验证、暂停与撤销。私有 SQLite 保存策略和最多 1000 条审计，界面读取最近 10 条。范围全文只在本地私有审阅/设置；任务报告只投影授权模式和枚举原因，不包含完整授权。

创建与每次额度预留先提交数据库，再签发绑定当前方案哈希、任务、最短期限的一次性执行凭据。成熟收据保存授权模式与信任 ID，实际写入仍在既有执行锁内。预留与收据分别落盘；记录失败不允许自动写入，崩溃不退额度。壁钟与本核心单调时钟都限制有效期；壁钟倒退到签发前也拒绝。

撤销先使内存权限和预留失效，再写审计，不等待检测门；写日志失败也不会恢复权限，但会报告无法确认持久化。它不撤回已写值，不撤销上传，不强杀补偿。停止任务同时暂停守护并撤销修改权限；仅暂停守护立即使当前票据失效，阻止下一自动写入，不等同撤销已有范围信任。每次写前重新核对范围、撤销、期限、任务与预留，已经写入的结果仍需验证/回退。任何非 `verified` 结果均暂停后续自动执行，包括成功回退；未知效果仍需核对，模型不能清除。

没有在途执行时，暂停/恢复守护可以继续使用仍有效的范围信任；如果暂停打断了已经开始准备的自动执行且结果非 `verified`，仍按执行异常规则暂停信任，需要重新审阅。

本版本不从磁盘恢复可执行权限。桌面断开/关闭不影响核心内信任；核心退出或异常重启后只保留审计和范围，需重新审阅。撤销写盘失败后也不能从旧记录自动恢复。停止流程即使授权审计失败仍释放核心资源。UID/私有凭据并非签名应用身份；跨重启自动信任须与后续签名执行器和安装生命周期一起扩展。

## 通信与界面

`review` 返回客户端/核心绑定的一次具体方案令牌，并附派生范围、哈希、模式限制和信任修订。`confirm_trust` 只接受任务 ID、方案哈希、令牌、`task`/`continuous` 和明确勾选。异客户端、旧/重复审阅、额外范围、动态方案和撤销后的修订均拒绝；排队等待期间的撤销同样使确认失效。

`revoke_trust` 与 `guard(enabled=false)` 是紧急权限收缩/暂停，不排在当前处理后；启用守护仍受普通协调。它们沿用操作 ID 去重和断线查询，不自动重发。

方案窗口展示三档模式、可读范围、完整 JSON、期限/额度和独立勾选。动态方案不提供范围选择。权限隐私页展示模式、对象/值/环境、范围哈希、到期、已用额度和撤销。总览来自执行器实际阶段，不把自动写入显示成普通守护检查。报告的授权依据只含枚举；通用 Authorization 凭据脱敏规则没有放宽。

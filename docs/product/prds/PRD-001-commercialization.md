# PRD-001 NetCare 商业化

版本 0.1，2026-09-26。依据：用户本任务要求参照 typeleast 目录，开启目标模式实施账号、官网与收费机制。以下为本轮实施基线与可调整的商业提案，不代表价格已上线销售或生产发布已获批准。

## 用户与价值

首发按个人 Mac 用户、开发者与远程工作者设计；企业团队版保留为后续范围。NetCare 帮用户区分本地网络、VPN/代理、DNS 与目标服务问题，让修复有证据且可回退。核心价值是解释故障，不承诺所有网络问题都能自动解决。

## 产品与收费

- NetCare Free：现有基础检测、菜单栏监测、结果查看、基础报告和用户确认的安全修复，永久免费且不依赖账号联网。
- NetCare Pro：30 天本地诊断历史、快照对比、脱敏 HTML/JSON 诊断包。诊断数据默认不上传。
- 初始价格提案：月度 ¥12、年度 ¥98，人民币整分由服务器定价；同一账号本人多台 Mac 使用。价格配置可调整，未接真实商户前不开放真实购买。
- Pro 试用 14 天，每账号一次，用户明确开启才起算。到期恢复 Free，不自动扣款、不删除已有诊断记录。
- 首期微信 Native 与支付宝电脑网站支付，主动购买/续期；续期保留剩余权益。团队组织、自动扣款和海外税务渠道后置。

## 本轮验收

1. 官网包含首页、功能、价格、下载、登录、账户、订单、支持与隐私/条款；移动端和深浅模式可用，无虚构客户/安装量/正式下载。
2. 邮箱验证码登录有有效期、尝试次数、限流与条款记录；账号隔离，会话可撤销；管理员与普通登录分离。
3. 桌面通过浏览器确认及 PKCE 轮询授权，凭证存 macOS Keychain；签名权益最多离线使用 7 天，免费检测不受认证服务影响。
4. 订单服务端定价、重复通知只发放一次；支付回调验签，退款只撤销对应权益，浏览器回跳不作为付款证据。
5. 开发邮件/模拟付款明确隔离；生产缺少安全配置时拒绝启动，未配支付/下载时呈现真实不可用状态。
6. 修复今早发现的固定 VPN 接口误报、异常被当健康、修复失败被当成功等发布阻断，并用模拟系统命令做回归，不实际修改用户网络。
7. 提供可重现本地启动、自动化证据、发布与回滚说明，区分本地闭环与真实生产验证。

## 外部发布条件

域名、经营主体/客服邮箱、SMTP、微信/支付宝商户、生产 PostgreSQL、Apple Developer ID/公证、真实第二台 Mac 安装尚待核验。会完成可审阅代码、页面和部署方案后再收集这些条件；不自动开通收费服务、不向真实用户发测试邮件。

## 3. 当前产品定位

当前阶段 Relay 先定位为“个人公司网络守护器”，优先保证以下场景稳定：

- UniVPN 已连接时使用公司 DNS；
- UniVPN 断开时避免公司 DNS 残留；
- 代理工具关闭后避免系统代理残留；
- IPv6 按当前工作环境需要保持关闭；
- 百度、Google、OpenAI 可达性作为日常网络健康信号。

通用化方向继续保留，但不抢先于个人场景的稳定性。

## 4. 修复动作安全化第一版

本次已给修复引擎加上第一层安全护栏：

- 修复前生成实际修复计划，并在 UI 确认框中展示；
- 修复前保存 DNS、系统代理开关、IPv6 状态快照；
- DNS 切公司 DNS 仅允许在 VPN 已连接场景执行；
- DNS 恢复公共 DNS 仅允许在 VPN 未连接或异常场景执行；
- 修复后重新检测目标问题；
- 如果目标问题仍存在，则自动按快照回滚，并再次刷新检测状态。
